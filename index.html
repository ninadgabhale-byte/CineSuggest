      Data Mining Pipeline

      Every recommendation passes through the same eight stages, from raw files to a ranked list.

      1. MovieLens Dataset

        Raw movies, users and ratings files published by GroupLens.

      2. Extract

        Read the raw files into Pandas DataFrames.

      3. Transform

        Clean records, split genres and build date attributes.

      4. Load

        Insert the cleaned tables into MySQL.

      5. Data Warehouse

        A star schema with one fact table and three dimensions.

      6. OLAP

        Roll-up, drill-down, slice and dice over the warehouse.

      7. Data Mining

        TF-IDF vectors and cosine similarity find related movies.

      8. Recommendation

        The Flask API returns the most similar titles.
