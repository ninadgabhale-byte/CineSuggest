    About the Project

    CineSuggest is a Data Warehousing and Data Mining project that analyzes movie ratings and movie characteristics to generate personalized movie recommendations.

    Dataset

    MovieLens Dataset

    MovieLens

    A public collection of movie ratings published by the GroupLens research lab at the University of Minnesota. It is widely used to study recommender systems.

    Three source tables

    Movies (title, year, genres), users (gender, age, occupation) and ratings (user, movie, score, timestamp). Together they hold around one million ratings.

    ETL

    Extract → Transform → Load

    1. Extract

      Read the raw movie, user and rating files with Pandas.

    2. Transform

      Remove duplicates, split genres, parse the release year and create date attributes.

    3. Load

      Write the clean tables into the MySQL data warehouse.

    Data Warehouse

    Star Schema: one central fact table surrounded by dimension tables. PK marks a primary key and FK a foreign key.

    DIM_MOVIE

    • PKmovie_id
    • title
    • genre
    • release_year

    DIM_USER

    • PKuser_id
    • gender
    • age
    • occupation

    FACT_RATING

    • PKrating_id
    • FKuser_id
    • FKmovie_id
    • rating
    • FKdate_id

    DIM_DATE

    • PKdate_id
    • day
    • month
    • quarter
    • year

    OLAP

    Roll-up, Drill-down, Slice and Dice

    Try the OLAP operations

    Roll-Up

    Aggregate to a higher level, for example movies into genres.

    GROUP BY year, genre WITH ROLLUP

    Drill-Down

    Move to finer detail, for example from year to month to day.

    GROUP BY year, month, day

    Slice

    Fix one dimension to a single value.

    WHERE release_year = 1999

    Dice

    Select a sub-cube using conditions on several dimensions.

    WHERE genre = 'Sci-Fi' AND release_year = 1999 AND rating >= 4

    Data Mining

    TF-IDF, Cosine Similarity and optionally K-Means Clustering

    TF-IDF

    Gives each genre or keyword a weight. Terms that are rare across all movies count for more than terms that appear everywhere.

    Cosine Similarity

    Measures how close two movie vectors point in the same direction. A score of 1 means identical content.

    K-Means Clustering (optional)

    Groups movies or users into clusters of similar items. It can be explored in WEKA before adding it to the Flask backend.
