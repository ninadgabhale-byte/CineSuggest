      How Recommendations Work

      The system is content-based: it compares what each movie is about, not what other people clicked.

      1. Select a Movie

        Pick a title you enjoyed.

      2. Extract Movie Features

        Genres and keywords become TF-IDF vectors.

      3. Calculate Similarity

        Cosine similarity compares the vectors.

      4. Generate Recommendations

        The closest movies are ranked and returned.

      Backend method: TF-IDF + Cosine Similarity

      The Flask backend builds a TF-IDF matrix from each movie's genres and tags, then measures the angle between the selected movie's vector and every other movie. A smaller angle means a higher similarity score.

      TF-IDF(t, d) = TF(t, d) × log(N / DF(t))

cosine(A, B) = (A · B) / (‖A‖ × ‖B‖)
